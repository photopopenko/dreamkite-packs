# DreamKite packs

Бесплатные темы для программ DreamKite Studio. Программы покупателей читают отсюда список тем и докачивают только новые.

## Как выпустить новую тему
1. Положите файл темы в папку продукта, например `quest/dinosaurs.json`.
2. Добавьте строку о ней в `quest/index.json` (id, version, name, tagline, url).
3. Сохраните изменения. Через 1–5 минут тему увидят все проданные копии.

## Правила
- Никогда не удаляйте и не переименовывайте файлы тем: у старых покупателей они уже есть, а новые покупатели скачивают их отсюда.
- Исправили тему — увеличьте `version` на 1 и в файле темы, и в `index.json`.
- Платные премиум-темы сюда не кладите: репозиторий публичный.
